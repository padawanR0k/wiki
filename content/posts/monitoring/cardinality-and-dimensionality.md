# 카디널리티

- 데이터 베이스의 측면에서의 카디널리티
  - 한 집합에 포함된 **데이터 값의 고유성**
    - 높은 카디널리티: 주민번호 컬럼의 주민번호
    - 낮은 카디널리티: 성별 컬럼의 남,녀

높은 카디널리티는 특정 데이터를 식별하거나 시스템을 이해하고자할 때 유용하다.

# 디멘셔널리티

- 데이터를 분석할 때 사용할 수 있는 **속성(키)의 개수**
- **디멘션을 조합**하면 더욱 세부적인 분석이 가능
- **즉, 디멘션이 많을수록, 분석할 수 있는 정보가 더 많아짐**
  - “지난 30분 동안 특정 서비스에서 특정 사용자 ID가 특정 요청을 보냈을 때 발생한 오류”
    - 시간, 서비스, 환경, 사용자, 요청 Url, 상태 라는 6가지 디멘션을 가지면 위와 같이 분석 가능
