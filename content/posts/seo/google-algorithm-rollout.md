Google이 검색 순위 알고리즘을 바꿀 때는 한 번에 적용하지 않고, 며칠에서 수주에 걸쳐 전체 검색 결과에 점진적으로 반영한다. 이걸 롤아웃이라고 부른다.

## 롤아웃 중에는 순위가 흔들리는 게 정상이다

롤아웃이 시작되면 검색어, 페이지, 지역마다 순위가 오르내린다. 완료됐다고 끝도 아니다. 그 뒤로도 순위는 계속 변할 수 있다.

지금 진행 중인 업데이트가 있는지는 [Google Search Status Dashboard](https://status.search.google.com/)에서 확인한다. (Core Update는 완료까지 보통 열흘 넘게 걸림)

## 서비스 배포와 달리 운영자가 제어할 수 없다

| 구분         | 서비스 롤아웃       | Google 검색 롤아웃        |
| ------------ | ------------------- | ------------------------- |
| 변경 주체    | 서비스 개발팀       | Google                    |
| 제어 가능성  | 배포·중단·롤백 가능 | 사이트 운영자가 제어 불가 |
| 관측 지표    | 오류율, 응답시간    | 검색 순위, 노출수, 클릭수 |

**Google은 어떤 비율과 순서로 배포하는지 공개하지 않는다.** 카나리 배포처럼 5% → 20% → 100%로 간다고 생각하면 안 된다.

## 순위가 떨어져도 바로 원인을 단정하지 않는다

- 롤아웃 중에는 지켜보기만 한다
- 완료되고 최소 1주일 뒤에 Search Console 데이터를 비교한다
	- 노출수, 클릭수, CTR, 평균 게재순위를 페이지·검색어 단위로
- 알고리즘 때문인지, 사이트 자체의 색인·렌더링·콘텐츠 문제인지 분리해서 본다

## 참고

- [Google Search Status Dashboard](https://status.search.google.com/) — 진행 중이거나 완료된 순위 업데이트 이력
- [Google 핵심 업데이트 가이드](https://developers.google.com/search/docs/appearance/core-updates?hl=ko) — 업데이트 이후 순위 변화 대응
